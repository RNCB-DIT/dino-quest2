# Дино-экспедиция — PWA

Сборка fe491612d2a8. Игра взята из dino-quest-chase-first.html без изменения её правил.

## Публикация через браузер
1. Создайте публичный репозиторий GitHub, например dino-quest.
2. Распакуйте ZIP. Загрузите содержимое архива в корень репозитория, сохранив папку icons.
   Не загружайте сам ZIP вместо файлов. index.html должен лежать в корне выбранного источника.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Откройте ссылку, показанную GitHub Pages. Не ссылку на исходный HTML на github.com и не raw-файл.
5. Используйте HTTPS. Пользовательский домен не нужен.

## iPhone
Safari → ссылка сайта → Поделиться → На экран «Домой» → Открывать как веб-приложение (если доступно) → Добавить.
Откройте установленную иконку С ИНТЕРНЕТОМ. Внизу страницы дождитесь «Офлайн-режим готов».
Закройте приложение, включите авиарежим и отдельно отключите Wi-Fi, затем снова откройте иконку.
Проверьте картинки, счётчик страниц и сохранение после повторного запуска.

## Прогресс
Сначала экспортируйте JSON в прежней версии. Затем импортируйте его в установленном приложении.
Данные хранятся локально в браузере/веб-приложении. Нет сервера, учётных записей и синхронизации.
Не публикуйте JSON-копии прогресса или PDF книги в репозитории.
Обновления не удаляют localStorage. Однако удаление данных сайта/приложения и ограничения браузера могут удалить данные: делайте резервные копии.
Первичная загрузка и загрузка обновлений требуют интернета.
Изображения встроены в index.html. Внешние CDN и библиотеки не используются.

## Обновления
Загружайте обновлённый комплект в тот же репозиторий и сохраняйте адрес сайта.
ВАЖНО: если меняете index.html вручную, меняйте VERSION в начале sw.js (например на 'v2').
Иначе старый офлайн-кеш продолжит отдавать прежний HTML. Обновляйте index.html и sw.js одним коммитом.
Новая версия скачивается в отдельный кеш и ожидает активации; кнопка «Установить обновление» появляется внизу.
Перед обновлением завершите расстановку и экспортируйте прогресс. Кнопка с подтверждением перезагрузит страницу.
Не очищайте данные сайта для обновления. При активации удаляются только старые кеши этого PWA, не сохранения и не кеши других проектов.

## Локальная проверка на компьютере
В папке проекта: python -m http.server 8000
Откройте http://localhost:8000/ — не file://.
Для iPhone используйте опубликованный HTTPS-адрес. HTTP по IP компьютера не обеспечивает обычный PWA-контекст.
